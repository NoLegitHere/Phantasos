# Phantasos

Phantasos is a programming language that compiles to native code. It is in
early development.

- The language specification and the C++ bootstrap compiler live in
  [Phantasos-Bootstrap](https://github.com/NoLegitHere/Phantasos-Bootstrap).
- [Hemera](https://github.com/NoLegitHere/Hemera) will hold the minimal C
  support code, linked here as a git submodule once it has code.
